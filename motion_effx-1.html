SECURITY LAYER

Protection for users & owner

FILES

Private object storage

Production media should live in a private bucket. Editors receive short-lived signed access rather than public URLs.

MALWARE

Upload scanning

Every uploaded file should be scanned and validated before it reaches an editor or processing worker.

ACCOUNTS

MFA & passkeys

Protect customer and admin accounts with strong authentication, session expiry, recovery controls and login throttling.

PAYMENTS

No card storage

Use a PCI-compliant payment processor. Your application should never store raw card numbers or CVV data.

ABUSE

Rate limits & quotas

Limit login attempts, requests, upload size, storage use and suspicious activity to reduce abuse and denial-of-service risk.

OWNER

Admin isolation

Use separate admin accounts, least privilege, audit logs, encrypted secrets, backups and alerts for sensitive actions.

PRIVACY

Retention controls

Define how long originals, finished files and project messages are retained, then automatically delete expired data.

NETWORK

HTTPS & secure headers

Production deployment should enforce HTTPS, HSTS, CSP, secure cookies, CSRF protection and strict content handling.

MONITORING

Audit & incident response

Log security events without exposing private media, monitor unusual behavior and maintain a tested breach-response process.

TRUST CENTER

Clear rules for everyone

Customer protection

Your media should be private by default. Access should be limited to authorized people, and download links should expire. Customers should be able to request deletion according to the site's retention policy.

Owner protection

The owner should not receive raw passwords or card data. Admin access should be isolated, logged and protected by MFA/passkeys, with backups and recovery procedures.

Content safety

Define prohibited uploads, copyright responsibilities, abuse reporting and a process for handling illegal or malicious files before launch.

Data minimization

Only collect information required to fulfill an order. Avoid storing unnecessary identity, payment or device information.
